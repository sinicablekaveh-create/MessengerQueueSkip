# THREE IB v3.3.1 • Send status and queue correctness

This patch addresses two defects in personal-account queues.

1. The gateway reports durable operation state independent of HTTP status. Mark a send `submitted` only if `results.state` is `succeeded`; even a 200 or 202 may mean queued, sending or unknown. For queued/sending, inspect `/send/operations/{send_id}` with the same connection identity, never re-submit.
2. Snapshot selected channel checkbox values on the Android UI thread before the asynchronous account validation worker; never read UI views from the worker.

If the operation is still incomplete, unavailable or uncertain, the app marks the recipient `review` and pauses that channel rather than retrying blindly. A 4xx definitive failure becomes failed except 409 and 429, which still require review.

No real OTP login or outbound delivery was tested. GoOmni is an unofficial implementation and subject to account/provider restrictions. Build is a Debug APK, not a production signed release.
